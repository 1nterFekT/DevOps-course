# Два контейнера и их роли

При прописывании `docker compose ps` я увидел два экземпляра - api и web

### Остановка/запуск

Командой `docker compose stop web` я остановил экземпляр web, доступ к нему по 127.0.0.1:8080 пропал. Командой `docker compose start web` я поднял его обратно

### Подтверждение заявки

После запуска экземпляра я зашел на 127.0.0.1:8080 и нажал на кнопку. Заявка была успешно создана

# Проверка понимания

> Удаляется ли образ при остановке web?

Нет, не удаляется, экземпляр останавливается, при этом сам образ продолжает работать
